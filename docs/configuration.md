# Configuration reference

Settings are loaded from environment variables, then `.env` in the working
directory. Compose overrides service addresses with internal hostnames. Secrets use
Pydantic `SecretStr`. Model settings reserve stable configuration names for upcoming
milestones; they do not imply that model integrations already exist.

| Variable | Default / purpose |
|---|---|
| `APP_ENV` | `development`; `test` permits SQLite; `production` validates secret/CORS settings |
| `LOG_LEVEL` | `INFO`; DEBUG/INFO/WARNING/ERROR |
| `DATABASE_URL` | Required PostgreSQL URL in development/production; SQLite memory only in test |
| `REDIS_URL` | `redis://localhost:6379/0`; broker and readiness probe |
| `QDRANT_URL` | `http://localhost:6333` |
| `QDRANT_API_KEY` | Optional secret; sent only to Qdrant |
| `JWT_SECRET` | No default; production requires at least 32 characters; auth implementation pending |
| `JWT_EXPIRY_MINUTES` | 30; 1–1440 |
| `CORS_ORIGINS` | JSON array, default `["http://localhost:5173"]`; explicit HTTPS in production |
| `STORAGE_ROOT` | `data/documents`; Compose uses `/data/documents` |
| `MAX_UPLOAD_BYTES` | 26214400 (25 MiB), 1 KiB–1 GiB; ingestion pending |
| `MAX_UPLOAD_FILES` | 10; 1–100; ingestion pending |
| `HEALTH_TIMEOUT_SECONDS` | 3; greater than 0 and at most 30, per dependency |
| `EMBEDDING_MODEL` | `sentence-transformers/all-MiniLM-L6-v2`; integration pending |
| `EMBEDDING_DIMENSION` | 384; 1–65536 |
| `EMBEDDING_DEVICE` | `cpu`; configured device support will be validated by model service |
| `EMBEDDING_BATCH_SIZE` | 32; 1–1024 |
| `RERANKER_ENABLED` | false |
| `RERANKER_MODEL` | `cross-encoder/ms-marco-MiniLM-L-6-v2` |
| `LLM_BASE_URL` | `http://localhost:11434/v1`; provider integration pending |
| `LLM_MODEL` | Empty; must be set before generation is enabled |
| `LLM_API_KEY` | Optional secret; provider-dependent |
| `RETRIEVAL_TOP_K` | 8; 1–100 |
| `RETRIEVAL_MIN_SCORE` | 0.35; dense cosine threshold, not a calibrated probability |
| `POSTGRES_DB` | Compose-only, `documind` |
| `POSTGRES_USER` | Compose-only, `documind` |
| `POSTGRES_PASSWORD` | Compose-only, generated by setup; no committed default |
| `GRAFANA_ADMIN_PASSWORD` | Compose-only, generated by setup |
| `DOCUMIND_INTEGRATION` | Test-only; `1` enables real dependency integration tests |

The setup script generates URL-safe hexadecimal database passwords. If manually
choosing passwords, URL-encode reserved characters in DATABASE_URL and review the
Compose interpolation accordingly. Do not print resolved Compose configuration to
shared logs; use `docker compose config --quiet`.

To refresh dependency locks deliberately using uv 0.7.13:

```sh
uv pip compile backend/requirements.txt --universal --python-version 3.12 -o backend/requirements.lock
uv pip compile backend/requirements-dev.txt --universal --python-version 3.12 -o backend/requirements-dev.lock
```

Then run the entire quality and security suite and review the lockfile diff.
